## 5. Ezt csináld meg egyszer (Kézi Teendők a saját gépeden / GitHubon)

Mivel ebben a futtatókörnyezetben nincs `.git` könyvtár, nincs `sudo`/`bubblewrap` és nincsenek fizikai LAN eszközeid, az alábbi lépéseket futtasd le egyszer a saját gépeden:

1. **Külön `fix/installer-and-recovery` branch, pontonkénti commitok és Pull Request létrehozása:**
   ```bash
   git checkout -b fix/installer-and-recovery
   git rm --cached -r --ignore-unmatch bun.lock .state.json .state.json.bak* .secrets.key .secrets.vault.json .config.json dev-dist novaswarm.sqlite* .novaswarm-setup.log .login-locks.json audit-chain.jsonl*
   git add -A
   git commit -m "fix(installer,auth,audit,ux): optional LAN password, E2E verification, CLI recovery, audit-chain.jsonl, hygiene & smart v9 checks"
   git push -u origin fix/installer-and-recovery
   # Ezután nyiss Pull Requestet GitHubon a fix/installer-and-recovery -> main ágra!
   ```

2. **Éles telepítés / Ollama újraválasztás a célhardveren:**
   A `chmod +x install.sh update.sh && ./install.sh` (vagy meglévő gépen a `npm run cli -- ollama-reselect`) detektálja a valódi CPU/RAM/GPU/tárhely adatokat, kiválasztja és szükség esetén letölti az optimális helyi Ollama csomagot, majd `tok/s` gyors-benchmarkot futtat. *(Megjegyzés: Gemini API kulcsokból több valódi kvótához külön Google Cloud projektekhez tartozó kulcsokat adj meg az AI Modellek & Router nézetben.)*

3. **Git History ellenőrzése (maradt-e titok korábbi commitokban — ne tisztítsd vaktában, előbb nézd meg):**
   ```bash
   git log --all --stat -- '.state.json*' '.secrets*' '.env*'
   git log --all -p -S 'TELEGRAM_BOT_TOKEN' -- '.env*' '.state.json*'
   ```
   Ha a fenti parancs találatot ad korábbi commitokban, akkor a `git-filter-repo` futtatása előtt/után minden érintett titkot **kötelezően rotálni kell**:
   ```bash
   pip install git-filter-repo
   git filter-repo --invert-paths \
     --path .state.json --path .state.json.bak1 --path .state.json.bak2 --path .state.json.bak3 \
     --path .secrets.key --path .secrets.vault.json --path .config.json --path .env --path dev-dist
   git push --force --all
   ```

4. **Kötelező kulcs- és token-rotáció (ha a `git log --all` találatot hoz `.state.json*`, `.secrets*` vagy `.env*` fájlokra):**
   - **Telegram Bot token**: állíts be újat a `@BotFather`-nél (`/revoke`).
   - **AI szolgáltatói API kulcsok**: cseréld le az összes érintett OpenAI / Gemini / Anthropic / OpenRouter / Groq / stb. kulcsot és vond vissza a régieket.
   - **Vault mesterkulcs (`.secrets.key` / `NOVASWARM_MASTER_KEY`) és webes operátori jelszó**: töröld/generáld újra a `.secrets.key`-t az éles szerveren, és állíts be új operátori jelszót az egyszeri setup-kóddal.
   - **Föderációs és webhook titkok / SSH költöztető kulcsok**: cseréld a `federationTokens`-t, webhook HMAC kulcsokat és az SSH kulcsokat/jelszavakat, ha valaha belekerültek az állapotfájlokba.

5. **OTA GPG-ellenőrzés és napi audit-horgony bekapcsolása:**
   - Írd alá GPG-vel a kiadási tageket (`git tag -s vX.Y.Z`), opcionálisan állítsd be a `/etc/systemd/system/novaswarm.service` fájlban az `Environment=NOVASWARM_VERIFY_TAG_SIG=1` sort (különben `auto` módban működik, és figyelmeztet, ha nincs aláírt tag).
